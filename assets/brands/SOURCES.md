# Logos d'entreprises intégrés

SVG repris du projet [Simple Icons](https://github.com/simple-icons/simple-icons), branche `develop`, le 26 novembre 2026. Leurs marques appartiennent à leurs titulaires ; l'utilisation vise l'identification éditoriale.

- `google.svg` : https://github.com/simple-icons/simple-icons/blob/develop/icons/google.svg
- `meta.svg` : https://github.com/simple-icons/simple-icons/blob/develop/icons/meta.svg
- `tether.svg` : https://github.com/simple-icons/simple-icons/blob/develop/icons/tether.svg
- `nvidia.svg` : https://github.com/simple-icons/simple-icons/blob/develop/icons/nvidia.svg

Ne pas produire de variantes inventées pour les autres groupes : la page utilise un monogramme tant qu'aucun SVG de provenance vérifiable n'a été validé. Walmart utilise, en complément, une URL Wikimedia Commons vers le symbole officiel 2025, avec un monogramme de repli.
